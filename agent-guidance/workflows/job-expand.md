# Job Expand Workflow

Canonical workflow for expanding the candidate profile.

## Steps

1. Scan profile files and source documents.
2. Inspect public professional sources linked by the user.
3. Identify new competency signals, evidence, and source tags.
4. Present proposed additions for confirmation.
5. Add confirmed facts to the profile guidance with source annotations.

## Rules

- Add only supported facts.
- Keep additions idempotent by recording sources.
