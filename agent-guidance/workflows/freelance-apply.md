# Freelance Apply Workflow

Workflow for drafting responses and tracking outcomes for freelance opportunities.

## Steps

1. Select a verified opportunity or user-supplied opportunity description.
2. Confirm source references, budget, timeline, and client/source context.
3. Load the default profile and freelance profile extension.
4. Draft a proposal, response outline, gig note, or follow-up using only verified facts.
5. Flag unsupported claims instead of inserting them into final material.
6. Save or update the freelance opportunity record with status, material references, notes, and outcome.

## Rules

- Never invent platform ratings, earnings, availability, client facts, or project details.
- Discovery leads must remain draft/needs-confirmation until original content is verified.
- Scam, ignored, and archived records should remain searchable for duplicate prevention.
