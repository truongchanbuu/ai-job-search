# Job Setup Workflow

Canonical workflow for onboarding and maintaining the candidate profile.

## Inputs

- Documents from `documents/`
- A pasted or referenced CV/resume
- Interactive answers from the user
- Existing profile guidance in `agent-guidance/job-application-assistant/`

## Steps

1. Offer three paths: documents folder, single CV import, or interview mode.
2. Inventory available documents and existing profile files.
3. Extract facts about identity, education, experience, skills, publications, awards, references, behavior, and job preferences.
4. Cross-check facts and surface conflicts before writing.
5. Update profile guidance, CV template, and search query guidance only after user confirmation.
6. Preserve placeholders when the repository is being used as a template.

## Outputs

- Updated candidate profile and behavioral guidance.
- Updated job evaluation criteria.
- Updated CV and cover-letter guidance.
- Updated job search query guidance.
