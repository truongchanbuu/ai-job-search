# Job Upskill Workflow

Canonical workflow for skill gap analysis and learning plans.

## Modes

- Aggregate mode: analyze tracker data and known postings.
- Targeted mode: analyze one job posting URL or pasted posting.

## Steps

1. Load candidate skills and target postings.
2. Identify hard-skill and domain gaps.
3. Group gaps into themes.
4. Find current learning resources with web search.
5. Save a dated report under `upskill/`.

## Rules

- Never invent courses, resources, or URLs.
- Include the current year in resource searches.
