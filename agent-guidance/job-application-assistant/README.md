# Job Application Assistant Guidance

This folder is the shared reference set for job application workflows across Codex and Claude compatibility wrappers.

Use these files as the canonical source for candidate facts, writing style, evaluation, CV tailoring, cover letters, and interview preparation. The original Claude files remain under `.claude/skills/job-application-assistant/` for compatibility.

## Files

- `01-candidate-profile.md`: candidate facts and professional history.
- `02-behavioral-profile.md`: behavioral profile and work preferences.
- `03-writing-style.md`: tone, structure, and claim-verification rules.
- `04-job-evaluation.md`: fit scoring framework.
- `05-cv-templates.md`: CV structure, compile rules, and ATS checks.
- `06-cover-letter-templates.md`: cover letter structure and compile rules.
- `07-interview-prep.md`: STAR examples and interview preparation.
