## Phase 5 structured evidence

Add reviewed entries to `evidence` in the front matter, using fields `id`,
`source` (e.g. `portfolio.md#project-name`), `context` (`employment`, `contract`,
`academic`, `training`, `personal`), `statement`, `verified`, `shareable`, and
`portfolio_url` (HTTPS or null). Set `verified` and `shareable` true only after
checking the fact and removing confidential details. Empty evidence is valid;
it blocks proposal claims rather than inventing experience. Unverified entries
are not sent to the provider. Identity skill proof prose is never sent.
