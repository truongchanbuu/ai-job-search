# Proposal writing preferences

status: TEMPLATE — edit privately

## Voice

- Natural, direct English; friendly but not overly formal.
- Start with the client's concrete problem, not generic self-introduction.
- Keep the first draft short and easy to scan.
- Prefer specific examples to adjectives and jargon.

## Structure

1. One personalized opening about the actual job.
2. A realistic first-step plan.
3. One relevant verified proof point.
4. One useful clarification question or next step.

## Avoid

- "I am passionate about...", "perfect fit", exaggerated promises.
- Invented results, fake clients, unverified delivery time/cost.
- Long generic introductions and irrelevant tool lists.

## Language and review

- Default: English unless the job clearly requires another language.
- I review final drafts and all screening answers before any submission.

## Minimal, problem-first defaults

- Put the client's concrete problem or result in the opening sentence.
- Describe the first useful action and how its result will be checked.
- Prefer one closely relevant, verified, shareable fact over a résumé summary.
- Use one useful question **or** one next step; avoid duplicate calls to action.
- Remove greetings/praise that delay the useful information. No generic sales pitch.
- Let missing facts remain unknown. Do not promise price, dates, availability or results.
- Use the shortest draft that answers the client's actual requirements; never pad to a word count.
- Select a proposal brief in Job Details; review facts and screening answers separately.
