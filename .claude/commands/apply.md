# /apply - Drafter-Reviewer Job Application Workflow

Claude compatibility wrapper.

Canonical workflow guidance now lives in:

- `agent-guidance/project-guide.md`
- `agent-guidance/workflows/job-apply.md`
- `agent-guidance/job-application-assistant/`

When `/apply` is invoked, read those files first and follow the shared workflow. Preserve the legacy behavior: evaluate fit before drafting, verify company-specific claims, tailor CV and cover letter, compile and inspect PDFs, run ATS extraction when available, and report verification results.
